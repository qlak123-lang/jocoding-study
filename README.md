# 🎰 로또 번호 추첨기 (Lotto Number Generator)

현대적인 웹 기술(Web Components)을 사용하여 제작된 로또 번호 추첨기입니다. 깔끔한 디자인과 다크/라이트 모드, 제휴 문의 기능을 포함하고 있습니다.

## 🚀 주요 기능

- **번호 생성:** 1부터 45까지의 숫자 중 중복 없는 6개의 숫자를 랜덤으로 추출합니다. (부드러운 애니메이션 포함)
- **테마 전환:** 다크 모드와 라이트 모드를 지원하며, 사용자의 설정은 브라우저에 저장되어 유지됩니다.
- **제휴 문의:** Formspree를 연동하여 비즈니스 제휴 문의를 직접 보낼 수 있습니다.
- **반응형 디자인:** 모바일과 데스크탑 어디서나 최적화된 화면을 제공합니다.

## 🛠 사용 기술

- **HTML5 / CSS3:** 네이티브 기술만을 사용하여 가볍고 빠릅니다. (CSS Variables, Flexbox 사용)
- **JavaScript (ES6+):** Web Components(Custom Elements, Shadow DOM)를 사용하여 모듈화된 설계를 구현했습니다.
- **Formspree:** 백엔드 코드 없이 폼 문의를 처리합니다.
